# ¿Qué skill necesito?

Ruta desde el problema que tienes hasta el archivo que lo cubre.

## Por situación

| Lo que está pasando | Skill |
|---|---|
| He resuelto algo y no sé si está bien | [`study-verifier`](study-verifier/SKILL.md) |
| Leo el enunciado y no sé por dónde entrar | [`study-planner`](study-planner/SKILL.md) |
| Veo dos caminos y no sé cuál cuesta menos | [`study-planner`](study-planner/SKILL.md) |
| Me sale un número raro y no sé por qué | [`study-verifier`](study-verifier/SKILL.md) |
| Sé hacer el tipo A pero necesito repetirlo hasta automatizarlo | [`study-drill`](study-drill/SKILL.md) |
| Me pierdo siguiendo una ejecución paso a paso | [`study-trace`](study-trace/SKILL.md) |
| Empiezo tema nuevo y solo tengo transparencias | [`study-notes`](study-notes/SKILL.md) |
| Acabo de hacer 15 problemas y tengo un desastre | [`study-consolidation`](study-consolidation/SKILL.md) |
| Fallo siempre en lo mismo y no sé en qué | [`study-consolidation`](study-consolidation/SKILL.md), parte B |
| Tengo una práctica y no sé qué estoy midiendo | [`study-lab`](study-lab/SKILL.md) |
| Examen en tres semanas y no sé qué repasar | [`study-exam`](study-exam/SKILL.md), parte B |
| Examen en dos semanas, quiero simulacros | [`study-exam`](study-exam/SKILL.md), parte A |
| Esto ya lo vi en otra asignatura y no encaja | [`study-bridge`](study-bridge/SKILL.md) |
| Me atasco y sospecho que me falta base de antes | [`study-bridge`](study-bridge/SKILL.md), parte B |
| Creo que lo entiendo pero no estoy seguro | [`study-active-learning`](study-active-learning/SKILL.md), parte B |
| Quiero construir el tema en vez de leerlo | [`study-active-learning`](study-active-learning/SKILL.md), parte A |
| Hay que memorizar, no razonar | [`study-exam`](study-exam/SKILL.md), parte C |

## Por momento del curso

```
Tema nuevo ................ study-notes  →  study-bridge (si viene de otra asig.)
Primer problema del tipo .. study-planner
Problemas siguientes ...... study-drill  +  study-verifier en todos
Práctica de laboratorio ... study-lab
Al cerrar el día .......... study-consolidation   (10 min)
Cada dos semanas .......... study-exam parte C sobre todo lo acumulado
3 semanas antes ........... study-exam parte B  (mapa de riesgo)
2 semanas antes ........... study-exam parte A  (simulacros, con reloj)
Última semana ............. libro de errores + lo marcado ALTO. Nada nuevo.
```

Detalle del tramo final en [`study-exam/calendar.md`](study-exam/calendar.md).

## Orden de prioridad

Si solo vas a incorporar un hábito: **`study-verifier` después de cada
problema que resuelvas**. Si vas a incorporar dos, el segundo es
**`study-consolidation` al cerrar el día**.

El resto suma, pero esos dos son los que cambian el resultado.

## Qué skill NO usar

- **No uses `study-planner` ni `study-verifier` para ver resolver.**
  Ambas asumen que el trabajo lo haces tú. Usadas antes de intentarlo,
  son una calculadora cara.
- **No uses `study-notes` si ya tienes un libro bueno.** Reescribir
  material sólido no aporta; la capa que aporta es la de errores,
  atajos y verificación.
- **No uses `study-drill` con un mecanismo que aún no entiendes.**
  Repetir sin comprender fija el error, no el método.
